# PRODIGY_DS_02
# Task 02 – Exploratory Data Analysis on Titanic Dataset

## 🎯 Objective
Perform data cleaning and exploratory data analysis (EDA) to understand survival patterns and relationships between features in the Titanic dataset.

## 📎 Dataset
- Titanic Dataset from [Kaggle](https://www.kaggle.com/c/titanic)

## 🧰 Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ⚙️ Task Workflow
- Handled missing values (Age, Embarked, etc.)
- Converted categorical variables to numeric (e.g., Sex, Embarked)
- Explored survival rates by gender, class, age group, etc.
- Visualized relationships using bar plots, heatmaps, pairplots

## 📊 Output
- Survival comparison charts by gender and class
- Correlation heatmap of features
- Age distribution of survivors vs non-survivors

## ✅ Learnings
- Data cleaning best practices
- Exploratory plotting techniques
- Identifying meaningful relationships between variables
